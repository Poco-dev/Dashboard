📌 Как пользоваться доской

Мышкой и пальцем

  • Двойной клик по доске — новая заметка
  • Двойной клик по заметке — редактировать
  • Тяни заметку, чтобы переклеить
  • Тяни булавку 📍 на другую заметку — нить
  • Кружок в углу — задача выполнена ✅
  • Уголок справа снизу — размер
  • Тяни пустое место — двигать доску
  • Shift + тянуть — выделить рамкой
  • Колёсико / щипок — масштаб
  • Правый клик / долгое нажатие — меню

Оформление текста

  • **жирный** → жирный
  • *курсив* → курсив
  • ~~зачеркнуть~~ → зачеркнуть
  • # Заголовок
  • - пункт — список
  • [ ] дело — чекбокс, кликабельный
  • #тег — клик по тегу ищет похожие
  • Ссылки https://… кликабельны

Всё сохраняется автоматически прямо в браузере. Чтобы перенести доску на другое устройство — «Скачать файл доски» или «Поделиться ссылкой» в меню ⋯.
