# 📌 Пробка — доска заметок

Пробковая доска в браузере: клеишь бумажки-стикеры, соединяешь их нитями как на детективной доске и отмечаешь выполненные задачи галочкой-штампом.

Работает на компьютере и на телефоне, её можно установить как приложение (PWA), и она открывается без интернета. Сборка не нужна: это чистые HTML, CSS и JavaScript без зависимостей.

## ✨ Возможности

**Заметки**
- Двойной клик по доске — новая заметка, двойной клик по заметке — редактирование
- 7 цветов бумажек, лёгкий наклон и тени, как у настоящих стикеров
- Перетаскивание, изменение размера, закрепление на месте
- Оформление текста: `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `# заголовок`, списки `- пункт`
- Чекбоксы `[ ] дело`, которые отмечаются кликом, и полоска прогресса по пунктам
- `#теги`: клик по тегу находит все заметки с ним
- Кликабельные ссылки
- Приоритет (`!`, `!!`, `!!!`) и срок выполнения с подсветкой «Сегодня» и «Просрочено»

**Выполнено ✅**
- Кружок в углу заметки ставит на ней зелёный штамп-галочку с анимацией, конфетти и звуком
- Когда выполнено всё, на доске праздник 🎉
- Прогресс в шапке и статистика по клику: сколько сделано, сколько просрочено, что на сегодня
- Фильтр «Все / В работе / Готово» и кнопка «Убрать выполненные»

**Нити 🧵**
- Потяни за булавку к другой заметке, и между ними протянется нить
- Режим нитей (клавиша `L`): клик по одной заметке, потом по другой
- Нить можно перекрасить, подписать, сделать прямой или провисающей
- Выдели несколько заметок и соедини их цепочкой одной кнопкой

**Доска**
- Бесконечное поле: двигай мышкой или пальцем, масштаб колёсиком или щипком
- Выделение рамкой (`Shift` + тянуть), групповые действия
- Миникарта, «Показать всё», авто-раскладка «Упорядочить»
- Несколько досок: создание, переименование, удаление
- 4 темы: пробковая, белая, грифельная, ночная
- Отмена и повтор (`Ctrl+Z` / `Ctrl+Shift+Z`)
- Копирование и вставка заметок; вставленный текст сам становится заметкой
- Поиск по тексту (`/`)
- Автосохранение в браузере и синхронизация между вкладками

**Поделиться и сохранить**
- «Сохранить картинкой»: PNG всей доски
- «Скачать файл доски» и «Загрузить из файла» (JSON; файл можно просто перетащить на доску)
- «Поделиться ссылкой»: вся доска упакована прямо в ссылку, сервер не нужен

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `N` | новая заметка |
| `Enter` | редактировать выделенную |
| `D` | выполнено / вернуть в работу |
| `L` | режим нитей |
| `1`–`7` | цвет заметки |
| `Del` | удалить |
| `Ctrl+Z` / `Ctrl+Shift+Z` | отменить / повторить |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+D` | копировать / вставить / дублировать |
| `Ctrl+A` | выделить всё |
| Стрелки | сдвинуть заметку (с `Shift` — сильнее) |
| `F` / `0` / `+` / `−` | показать всё / 100% / масштаб |
| `/` | поиск |
| `?` | справка |

## 🚀 Как залить в интернет

### Вариант 1. GitHub Pages (бесплатно, уже настроено)

В репозитории лежит готовый workflow `.github/workflows/pages.yml`.

1. Влей эту ветку в `main` (через Pull Request или напрямую).
2. На GitHub открой **Settings → Pages** и в **Build and deployment → Source** выбери **GitHub Actions**.
3. Если деплой не запустился сам, открой вкладку **Actions**, выбери «Публикация на GitHub Pages» и нажми **Run workflow**.
4. Через минуту сайт появится по адресу `https://<твой-логин>.github.io/<имя-репозитория>/`.

Каждый следующий пуш в `main` обновит сайт автоматически.

### Вариант 2. Netlify Drop (без аккаунта на GitHub)

1. Скачай папку проекта.
2. Открой <https://app.netlify.com/drop> и перетащи туда папку.
3. Готово, Netlify выдаст ссылку.

### Вариант 3. Vercel / Cloudflare Pages

Импортируй репозиторий. Фреймворк: **Other**, команда сборки пустая, папка для публикации — корень проекта (`.`).

## 📱 Установка как приложение

Открой сайт:
- **Android / Chrome**: меню ⋮ → «Установить приложение» (или «Добавить на главный экран»)
- **iPhone / Safari**: «Поделиться» → «На экран «Домой»»
- **Компьютер / Chrome, Edge**: значок установки в адресной строке

## 💻 Запуск на своём компьютере

Достаточно открыть `index.html` в браузере. Чтобы работали офлайн-режим и установка, нужен любой локальный сервер:

```bash
python3 -m http.server 8000
# потом открой http://localhost:8000
```

## 📁 Структура

```
index.html            — разметка, иконки, справка
css/style.css         — оформление, темы, анимации
js/app.js             — вся логика доски
sw.js                 — офлайн-режим (service worker)
manifest.webmanifest  — настройки установки как приложения
icons/                — иконки приложения
.github/workflows/    — автодеплой на GitHub Pages
```

## 🔒 Где хранятся данные

Всё хранится только в твоём браузере (`localStorage`) и никуда не отправляется. Если очистить данные сайта, доски пропадут, поэтому время от времени сохраняй резервную копию через «Скачать файл доски».
